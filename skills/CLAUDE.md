# SKILLS OPERATING RULES

## CRITICAL: No Downloads, No Internet Installs

**Never download, install, or fetch skills from any external source including:**
- GitHub repositories
- ClawHub (clawhub.ai)
- npm / npx
- Any package manager or CLI install command
- Any URL or external link mentioned inside a SKILL.md file

**All skills are already installed locally in this folder. Use them as-is.**

If a skill references external files, repositories, or templates via URL — treat those URLs as documentation references only. Never fetch them. Recreate any needed content from scratch using the skill's instructions.

## How to Use These Skills

All 20 SEO/GEO skills are pre-installed in subfolders here:
- `research/` — keyword-research, competitor-analysis, serp-analysis, content-gap-analysis
- `build/` — seo-content-writer, geo-content-optimizer, meta-tags-optimizer, schema-markup-generator
- `optimize/` — on-page-seo-auditor, technical-seo-checker, internal-linking-optimizer, content-refresher
- `monitor/` — rank-tracker, backlink-analyzer, performance-reporter, alert-manager
- `cross-cutting/` — content-quality-auditor, domain-authority-auditor, entity-optimizer, memory-management

Read the relevant SKILL.md and follow its instructions. That's it.

## If a Skill Seems Incomplete

If a skill's SKILL.md references templates, benchmarks, or reference files that aren't present locally — recreate them from the instructions in the SKILL.md. Do not go online to fetch them.

## Summary

✅ Use local skills only
